# 1. 다음과 같이 테이블을 정의하고 튜플을 삽입하였을 때, 각 번호에 SQL문을 실행한 결과를 적으시오.

```sql
CREATE TABLE 부서 (
    부서코드 INT PRIMARY KEY,
    부서명 VARCHAR(20)
);

CREATE TABLE 직원 (
    직원코드 INT PRIMARY KEY,
    부서코드 INT,
    직원명 VARCHAR(20),
    FOREIGN KEY(부서코드) REFERENCES 부서(부서코드)
    ON DELETE CASCADE
);

INSERT INTO 부서 VALUES(10, '영업부');
INSERT INTO 부서 VALUES(20, '기획부');
INSERT INTO 부서 VALUES(30, '개발부');

INSERT INTO 직원 VALUES(1001, 10, '이진수');
INSERT INTO 직원 VALUES(1002, 10, '곽명경');
INSERT INTO 직원 VALUES(1003, 20, '김건길');
INSERT INTO 직원 VALUES(1004, 20, '최민수');
INSERT INTO 직원 VALUES(1005, 20, '이용광');
INSERT INTO 직원 VALUES(1006, 30, '한성광');
INSERT INTO 직원 VALUES(1007, 30, '박미경');
```

### 실행 SQL ①

```sql
SELECT DISTINCT COUNT(부서코드) FROM 직원 WHERE 부서코드 = 20;
```

**결과:** <font color="#262626">3</font>

*해설 :*
- `DISTINCT(중복 제거)`는 `부서코드`가 아닌 `COUNT(부서코드)`에 적용되므로, 여전히 부서코드가 20인 컬럼의 수 '3'이 된다.

### 실행 SQL ②

```sql
DELETE FROM 부서 WHERE 부서코드 = 20;
SELECT DISTINCT COUNT(부서코드) FROM 직원;
```

**결과:** <font color="#262626">4</font>

*해설 :*
- `부서코드`가 20인 컬럼을 삭제한 후, 모든 직원테이블의 부서코드 개수를 센다. 이때 `DISTINCT(중복 제거)`는 `COUNT`에 적용되므로
여전히 '4'이다.

# 2. 학생(STUDENT) 테이블에서 SQL 실행 결과로 표시되는 *튜플의 수*를 예측하시오.
* DEPT는 '학과'를 뜻한다

가정: 전기과 학생 50명, 전자과 학생 100명, 전산과 학생 50명

### 실행 SQL ①

```sql
SELECT DEPT FROM STUDENT;
```

**결과:** <font color="#262626">200</font>

### 실행 SQL ②

```sql
SELECT DISTINCT DEPT FROM STUDENT;
```

**결과:** <font color="#262626">3</font>

*해설 :*
- 전기/전자/화학 3가지 종류로 이루어진 DEPT 속성의 중복을 제거하면 '3'이 남는다.
### 실행 SQL ③

```sql
SELECT COUNT(DISTINCT DEPT) FROM STUDENT WHERE DEPT = '전산과';
```

**결과:** <font color="#262626">1</font>

*해설 :*
- 전산과인 학생들의 학과를 뽑는다. 이후 해당 학과의 중복을 제거하면 1개만 남게 된다.

# 3. 다음 SQL문에서 괄호 안에 들어갈 알맞은 내용을 작성하시오.
- 'H'제조사의 '단가' 보다 높은 '단가'를 가진 제품의 정보를 조회하는 SQL문이다.

```sql
SELECT 제품명, 단가, 제조사
FROM 제품
WHERE 단가 > (    ) (SELECT 단가 FROM 제품 WHERE 제조사 = 'H');
```

**답:** <font color="#262626">`ALL`</font>

*해설 :*
- 해당 쿼리는, where절의 하위 질의에 결과를 반영하여 본 질의의 조건에 추가하는 SQL이다.
- 만약 서브쿼리에서 'H'제조사의 제품의 단다가 100/200/400 이 나왔다면,
- 해당 단가들 보다 높은 단가를 찾기 위해서는 100/200/400을 모두 비교하여야 한다.
- 따라서 `ALL`키워드가 들어간다면 모든 단가를 비교할 수 있다.

# 4. 아래 테이블을 기반으로 SQL 실행 결과를 예측하시오.

**TABLE**

| INDEX | COL1 | COL2 |
| ----- | ---- | ---- |
| 1     | 2    | NULL |
| 2     | 4    | 6    |
| 3     | 3    | 5    |
| 4     | 6    | 3    |
| 5     | NULL | 3    |

### 실행 SQL

```sql
SELECT COUNT(COL2)
FROM TABLE
WHERE COL1 IN (2, 3)
    OR COL2 IN (3, 5);
```

**결과:** <font color="#262626">3</font>

*해설 :*
- COL1 컬럼에 2나 3이 포함되었거나, COL2컬럼에 3이나 5가 포함된 컬럼 (4개)를 찾는다,

| COL2 |
| ---- |
| NULL |
| 5    |
| 3    |
| 3    |
- 여기서 **NULL은 COUNT에 집계가 되지 않으므로** 답은 '3'이다.

# 6. 다음 `<속성 정의서>`를 참고하여 `<학생>` 테이블에 대해 20자의 가변 길이를 가진 `주소` 속성을 추가하는 `<SQL문>`을 완성하시오. 
(단, SQL문은 ISO/IEC 9075 표준을 기반으로 작성하시오.) 
## 속성 정의서 

| 속성명   | 데이터타입   | 제약조건    | 테이블명 |
|----------|-------------|------------|----------|
| 학번     | CHAR(10)    | UNIQUE     | 학생     |
| 이름     | VARCHAR(8)  | NOT NULL   | 학생     |
| 주민번호 | CHAR(13)    |            | 학생     |
| 학과     | VARCHAR(16) | FOREIGN KEY | 학생     |
| 학년     | INT         |            | 학생     |

## SQL문
```sql 
( 1 ) TABLE 학생 ( 2 ) 주소 VARCHAR(20);
```

**답 :**
1 -> ALTER
2 -> ADD

*해설 :*
- 속성을 추가한다 -> 테이블을 수정한다 -> ALTER
- **ALTER + ADD** 속성 추가.

# 7. 다음 `<학생>` 테이블을 참고하여 `<처리 조건>`에서 요구하는 SQL문을 작성하시오.

## 학생 테이블

| 학번 (varchar) | 이름 (varchar) | 학년 (number) | 수강과목 (varchar) | 점수 (number) | 연락처 (varchar) |
| ------------ | ------------ | ----------- | -------------- | ----------- | ------------- |
| 20E0232      | 김민영          | 3           | 세무행정           | 4.5         | 010-5412-4544 |
| 19D0024      | 이성화          | 2           | 토목개론           | 3           | 010-1548-4796 |
| 20E0135      | 성유수          | 4           | 실용법학           | 3.5         | 010-9945-7411 |
| 20E0511      | 유인혁          | 1           | 데이터론           | 2           | 010-3451-4972 |

## 처리 조건

1. **3, 4학년의 학번, 이름을 조회한다.**
2. **IN 예약어를 사용해야 한다.**
3. **속성명 아래의 괄호는 속성의 자료형을 의미한다.**

**정답 :**

```sql
SELECT 학번, 이름 FROM 학생 WHERE 학년 IN (3, 4);
```

*해설 :*
- *IN*예약어는 WHERE절과 함께 쓰이며, `WHERE 속성 IN (조건,조건,...)` 방식으로 사용된다.
- 해당 조건을 포함하고 있는 모든 속성이 선택되게 된다.
