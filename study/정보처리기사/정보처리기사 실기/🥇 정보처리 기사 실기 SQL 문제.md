```sql
CREATE TABLE 부서 (
    부서코드 INT PRIMARY KEY,

    직원코드 INT PRIMARY KEY,

    FOREIGN KEY(부서코드) REFERENCES 부서(부서코드)

);

INSERT INTO 부서 VALUES(10, '영업부');
INSERT INTO 부서 VALUES(20, '기획부');

INSERT INTO 직원 VALUES(1001, 10, '이진수');

```

### 실행 SQL ①

```sql
SELECT DISTINCT COUNT(부서코드) FROM 직원 WHERE 부서코드 = 20;
```

**결과:** <font color="#262626">3</font>

*해설 :*
- `DISTINCT(중복 제거)`는 `부서코드`가 아닌 `COUNT(부서코드)`에 적용되므로, 여전히 부서코드가 20인 컬럼의 수 '3'이 된다.

### 실행 SQL ②

```sql
DELETE FROM 부서 WHERE 부서코드 = 20;
SELECT DISTINCT COUNT(부서코드) FROM 직원;
```

**결과:** <font color="#262626">4</font>

*해설 :*
- `부서코드`가 20인 컬럼을 삭제한 후, 모든 직원테이블의 부서코드 개수를 센다. 이때 `DISTINCT(중복 제거)`는 `COUNT`에 적용되므로
여전히 '4'이다.

# 3. 다음 SQL문에서 괄호 안에 들어갈 알맞은 내용을 작성하시오.
- 'H'제조사의 '단가' 보다 높은 '단가'를 가진 제품의 정보를 조회하는 SQL문이다.

```sql
SELECT 제품명, 단가, 제조사
FROM 제품
WHERE 단가 > (    ) (SELECT 단가 FROM 제품 WHERE 제조사 = 'H');
```

**답:** <font color="#262626">`ALL`</font>

*해설 :*
- 해당 쿼리는, where절의 하위 질의에 결과를 반영하여 본 질의의 조건에 추가하는 SQL이다.
- 만약 서브쿼리에서 'H'제조사의 제품의 단다가 100/200/400 이 나왔다면,
- 해당 단가들 보다 높은 단가를 찾기 위해서는 100/200/400을 모두 비교하여야 한다.
- 따라서 *ALL*키워드가 들어간다면 모든 단가를 비교할 수 있다.

*서브쿼리 앞에 아무 키워드도 붙지 않는다면, 서브쿼리가 다중 행일때 오류를 발생시킨다.*
*이때, `ANY`나 `ALL` 연산자를 사용하여 다중행을 비교할 수 있다.*

`ANY` -> 서브쿼리 결과 중 하나라도 참이면 해당 행은 참
`ALL` -> 서브쿼리 결과 중 모든 것에 참이어야 해당 행은 참

### ✅ **1) 순수 관계 연산 (기본 연산)**

이 연산들은 관계형 데이터베이스의 데이터를 검색하고 변형하는 데 사용됩니다.

| 연산                             | 기호  | SQL 연산                      | 설명                    |
| ------------------------------ | --- | --------------------------- | --------------------- |
| **선택 (Selection, σ)**          | `σ` | `WHERE`                     | 특정 조건을 만족하는 튜플(행)만 선택 |
| **투영 (Projection, π)**         | `π` | `SELECT (열 선택)`             | 특정 속성(열)만 선택          |
| **교차곱 (Cartesian Product, ×)** | `×` | `CROSS JOIN`                | 두 테이블의 모든 조합을 반환      |
| **조인 (Join, ⨝)**               | `⨝` | `INNER JOIN`, `LEFT JOIN` 등 | 공통 속성을 기준으로 두 테이블을 연결 |
| **나누기 (Division, ÷)**          | `÷` | `EXISTS`, `NOT EXISTS`      | 특정 조건을 만족하는 튜플만 선택    |

### ✅ **2) 집합 연산 (Set Operations)**

관계 대수에서 테이블을 하나의 집합(Set)으로 간주하고 수행하는 연산입니다.

|연산|기호|SQL 연산|설명|
|---|---|---|---|
|**합집합 (Union, ∪)**|`∪`|`UNION`|두 테이블의 모든 튜플을 합친 후 중복 제거|
|**교집합 (Intersection, ∩)**|`∩`|`INTERSECT`|두 테이블에서 공통된 튜플만 반환|
|**차집합 (Difference, -)**|`−`|`EXCEPT`, `MINUS`|첫 번째 테이블에서 두 번째 테이블에 없는 튜플 반환|

# 10. <성적>` 테이블에서 과목별 점수의 평균이 90점 이상인 과목이름, 최소점수, 최대점수를 검색하고자 한다.  
`<처리 조건>`을 참고하여 적합한 SQL문을 작성하시오.

## `<성적>` 테이블

| 학번   | 과목번호 | 과목이름    | 학점 | 점수 |
|--------|--------|------------|----|----|
| a2001  | 101    | 컴퓨터구조  | 6  | 95  |
| a2002  | 101    | 컴퓨터구조  | 6  | 84  |
| a2003  | 302    | 데이터베이스 | 5  | 89  |
| a2004  | 201    | 인공지능    | 5  | 92  |
| a2005  | 302    | 데이터베이스 | 5  | 100 |
| a2006  | 302    | 데이터베이스 | 5  | 88  |
| a2007  | 201    | 인공지능    | 5  | 93  |

## `<결과>`

| 과목이름    | 최소점수 | 최대점수 |
|------------|--------|--------|
| 데이터베이스 | 88     | 100    |
| 인공지능    | 92     | 93     |

## `<처리 조건>`

- WHERE문은 사용하지 않는다.
- `GROUP BY`와 `HAVING`을 이용한다.
- 집계함수(Aggregation Function)를 사용하여 명령문을 구성한다.
- `최소점수`, `최대점수`는 별칭(Alias)을 위한 `AS`문을 이용한다.
- 명령문 마지막의 세미콜론(;)은 생략 가능하다.
- 인용 부호가 필요한 경우 작은따옴표(`'`)를 사용한다.

**정답 :**
```sql
SELECT 과목이름, MIN(점수) AS 최소점수, MAX(점수) AS 최대점수 
FROM 성적 
GROUP BY 과목이름 
HAVING AVG(점수) >= 90;
```

*해설 :*
- 과목이름별로 여러 점수의 통계를 내는것 이기 때문에, **GROUP BY 과목이름**을 사용한다.
- 이때, *GROUP BY ~ HAVING 조건* 을 사용하여, ==해당 그릅화된 데이터 중 다음 조건을 만족하는 그룹만 포함한다.==

## `<SQL문>`

```sql
SELECT COUNT(*) CNT 
FROM A 
CROSS JOIN B
```

- `SELECT COUNT(*) CNT` 에서 CNT는 *as CNT* 가 생략된 형태이다.

A테이블의 모든 행과, B테이블의 모든 행의 모든 가능한 조합을 구한다.

| A.NAME | B.RULE |

| Smith  | %T%    |

| Allen  | %T%    |
| Scott  | S%     |
| Scott  | %T%    |
따라서, 저 중 a.name컬럼이 b.rule을 따르는(*like* 연산을 했을 때, 참인 결과는)

| Smith | S%  |
| ----- | --- |
| Smith | %T% |
| Scott | S%  |
| Scott | %T% |
총 4개이다.
