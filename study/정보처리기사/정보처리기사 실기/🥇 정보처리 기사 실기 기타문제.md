#  LRU 페이지 교체 알고리즘에 따른 페이지 부재 횟수를 작성하시오. (프레임 3칸)

```java
7 0 1 2 0 3 0 4 2 3 0 3 2 1 2 0 1 7 0 1
```

- **LRU**(Least Recently Used)​​는 가장 오랫동안 사용되지 않는 녀석을 교체한다.
- **LFU**(Least Frequently Used)는 최소 사용횟수 우선 교체 이다. 동일한 빈도의 경우, 가장오래된 페이지를 선택.
>[!warning]  주의
> 부재 횟수를 구할떄, 초기 비어있는 프레임에 페이지가 삽입될때도 횟수를 센다.

# 다음 JAVA코드의 실행 순서를 중복없이 적으시오
```java
class Parent {
    int x, y;
 
    Parent(int x, int y) { //1
        this.x=x;
        this y=y;
    }
 
    int getT() { //2
        return x*y;
    }
}
 
​class Child extend Parent {
    int x;
 
    Child (int x) { //3
        super(x+1, x);
        this.x=x;
    }
 
    int getT(int n){ //4
        return super.getT()+n;
    }
}
 
class Main {
    public static void main(String[] args) { //5
        Parent parent = new Child(3); //6
        System.out.println(parent.getT()); //7
    }
}

실행 순서 : 5 → ( ) → ( ) → ( ) → ( ) → ( )
```

- `new Child(3)`로 Child클래스의 생성자가 실행된다. *6 → 3*
- 이후 super에서 Parent의 생성자가 실행된다. *3 → 1*
- 그리고 7번 print가 실행되면, 다형성에 의해 2번 getT가 실행된다. *7 → 2*
### 답 : 
> 5 → 6 → 3 → 1 → 7 → 2
