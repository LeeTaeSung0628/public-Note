# C로 구현된 프로그램을 분석하여 그 실행 결과를 쓰시오
```java
#include <stdio.h>
main() { 
	int s, el = 0;
	for (int i = 6; i <= 30; i++) {
		s = 0;
		for (int j = 1; j <= i / 2; j++)
			if (i % j == 0)
				s = s + j;
			if (s == i)
				el++;
	}
	printf("%d", el);
}
```
- `j <= i / 2;` -> 나머지가 몇이든 버린다.
- 하나하나 분석하면, 
1. 6~30까지 *자신의 약수*(나누어 떨어지는 수)를 모두 더한다
2. 모두 더한 수와 자신이 같은지 판단하여 출력한다.
3. 6과 28이 해당한다.

# java로 구현된 프로그램 실행결과를 작성하시오.
```java
public class Test { 
	public static void main(String[] args) { 
		int w = 3, x = 4, y = 3, z = 5; 
		if((w == 2 | w == y) & !(y > z) & (1 == x ^ y != z)) { 
			w = x + y; 
			if(7 == x ^ y != w)
				System.out.println(w);
			else 
				System.out.println(x); 
		} 
		else {
			w = y + z; 
			if(7 == y ^ z != w)
				System.out.println(w); 
			else 
				System.out.println(z); 
			}
		}
	}
```
1. & , | -> 비트 연산으로써, 2진법을 비트연산하면 된다.

2. x ^ y 연산은 비트 `XOR`연산으로써, 
	001 -> y != z
	000 -> 1 == x
	--- (***같으면 0 / 다르면 1***)
	001 -> 4 가 된다.

# 다음 Python으로 구현된 프로그램의 출력을 쓰시오.
```python
a = 100 
result = 0 
for i in range(1,3):
	result = a >> i
	result = result + 1 
print(result)
```
1. i = 1,2 수행
2. a >> i 는 오른쪽 시프트 연산자로써, *a값을 오른쪽으로 i비트 움직인다는 뜻이다.*
3. 파이썬에서 정수는 4Byte이므로, 8bit x 32개 로 계산하면 된다.

0000 ... 0001100100 -> 100 (4 + 32 + 64)
- 시프트 연산을 한번 수행하면
0000 ... 0000110010 -> 50 (2 + 16 + 32)
+1 을 하면 **51** -> 110011

- 한번 더 수행하면 100을 두칸 시프트 한다
0000 ... 0000011001 -> 25 (1 + 8 + 16)
25+1 = **26**

>[!tip] 파이썬의 `print` 
> 기본적으로 파이썬의 `print`는 `print(end='\n')` 이 포함된 식이다. (줄바꿈 디펄트)
> 즉 `print("123", end=' '`)로 표현하면 줄바꿈 대신 공백이 삽입된다.

# 다음 JAVA코드는 10진수를 2진수로 변환하는 프로그램이다. 빈칸을 채워라
```java
public class Test { 
	public static void main(String[]args) { 
		int a[] = new int[8]; 
		int i = 0; 
		int n = 10; 
		while( "( 1 )" ) { 
			a[i++] = "( 2 )";
			n /= 2; 
		} 
		for(i = 7; i >= 0; i--)
			System.out.print(a[i]); 
	} 
}
```
- `n /= 2;`란 `n = n / 2`랑 동일한 문법이다.

먼저, 10진수를 2진수로 변환하기 위해서는, 2로 계속해서 나누어, 나머지를 삽입하면된다.
```
10 / 2 = 5(0)
5 / 2 = 2(1)
2 / 2 = 1(0)
 (1)
10 -> 1010 (8+2)

19 / 2 = 9(1)
9 / 2 = 4(1)
4 / 2 = 2(0)
2 / 2 = 1(0)
(1)
19 -> 10011 (16+2+1)
```

*JAVA는 배열 선언시 초기화를 하지 않으면 `0` 이 삽입된다*
*`a[i++] = x` 를 수행하면 i번째 자리에 값 삽입 후, i값을 증가시킨다.*

1. 첫번째 조건식에는 **n > 0**을 넣는다.
2. 16일때, a[] 배열에는 11001 순서로 들어가게된다.
3. **n % 2**(나머지가 계속 들어간다.)
	10 -> 5 -> 2 -> 1 -> **0(조건식에 부합) 실행 X**
	0     1    0    1
	a = [0,1,0,1,0,0,0,0]
4. 를 역순으로 출력하면 1010 이 된다.
출력은 `00001010`이 된다.
