# <font color="#9bbb59">클라우드 네이티브 아키텍처(Cloud-Native Architecture)</font>

- CNA는 클라우드 환경의 특성을 최대한 활용하여 애플리케이션을 설계하고 운영하는 접근 방식이다.
- 이는 **유연성, 확장성, 탄력성, 복원성 등의 장점을 극대화**하여 빠르게 변화하는 비즈니스 요구에 대응할 수 있도록 하기 위함이다.

## 1. 등장 배경

- **클라우드(AWS, Azure 등..)의 보편화**에 따라, 해당 환경(클라우드 시스템 환경)에 맞는 적절한 프로그램(애플리케이션)설계 기법이 필요해졌고, 그렇게 등장한 것이 <u>클라우드 네이티브 아키텍처 CNA</u>이다.
