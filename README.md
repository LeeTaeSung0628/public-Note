# Public Note Collection

This repository holds personal notes written primarily in **Korean**. It is organized as an Obsidian vault and includes a small custom HTML file for additional styling.

## Viewing the notes

You can read the notes directly on GitHub by browsing the Markdown files. The main entry point is [`🏠 taesung's Blog.md`](🏠%20taesung's%20Blog.md). For a nicer reading experience, open the generated HTML pages with an Obsidian-compatible viewer. The file [`custom-head-content.html`](custom-head-content.html) applies a dark theme and adds a floating “back to top” button.

## Note categories

- **Projects** – development logs in [`project/`](project/).
- **Issues & Troubleshooting** – problem analyses in [`Issue_TroubleShooting/`](Issue_TroubleShooting/) with an overview in [`🔫 이슈 분석 & 트러블슈팅.md`](project/🔫%20이슈%20분석%20&%20트러블슈팅.md).
- **Study** – summaries of study topics in [`study/`](study/) with an index in [`📕 공부.md`](study/📕%20공부.md).
- **Tools** – notes on tools such as AWS, Docker, and Jenkins in [`Tools/`](Tools/) linked from [`🪓 도구.md`](Tools/🪓%20도구.md).
- **Lectures & Certifications** – lecture notes and exam preparation materials in [`lectur/`](lectur/) referenced from [`🏫 강의 & 자격증.md`](lectur/🏫%20강의%20&%20자격증.md).
- **Short Keywords** – quick reference entries under [`짧은 키워드/`](짧은%20키워드/).

Attachments and screenshots are stored in the [`사진 및 문서/`](사진%20및%20문서/) folder.
